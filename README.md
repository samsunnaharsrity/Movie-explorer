# Movie Explorer

> A modern, responsive and interactive movie discovery application built with React.

Movie Explorer is a responsive web application that allows users to explore movies, search for specific titles, and view detailed movie information through an interactive interface.

---

## Live Demo

https://movie-explorer-nu-nine.vercel.app/

## GitHub Repository

https://github.com/samsunnaharsrity/Movie-explorer

---

## Project Overview

Movie Explorer was developed as part of the Apollo Level 2 Web Development Foundation Program – Assignment 2.

The main objective of this project is to build a user-friendly movie browsing experience using React while practicing component-based development, routing, state management, search functionality, modal implementation, and responsive UI design.

---

## Features

### Movie Browsing

Users can explore movies through a clean and organized movie card layout.

### Movie Search

Users can search for specific movies by entering a movie title.

### Movie Details

Users can view detailed information about a selected movie without leaving the current page.

### Interactive Modal

Movie details are displayed inside an interactive modal for a better user experience.

### Navigation

A responsive navigation bar allows users to easily navigate between different sections of the application.

### Responsive Design

The application is designed to work smoothly across different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile

### Reusable Components

The application follows a component-based architecture to keep the code organized, reusable, and maintainable.

## Getting Started

Follow the steps below to run the project locally.

### Clone the Repository

```bash
git clone https://github.com/samsunnaharsrity/Movie-explorer.git
```

### Navigate to the Project Directory

```bash
cd Movie-explorer
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

### Open in Browser

After starting the development server, open:

```text
http://localhost:5173
```
